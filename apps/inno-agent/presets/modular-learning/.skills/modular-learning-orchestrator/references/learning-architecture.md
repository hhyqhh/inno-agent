# Learning Architecture

## Map, Block, Context

- **Domain map:** a small orientation view of concepts, mechanisms, examples, contrasts, and open questions.
- **Knowledge block:** an independently understandable concept with a definition, origin, mechanism, multiple uses, boundaries, related blocks, and sources.
- **Context:** a bounded application environment. It tests a block; it does not define the block.

The same block should enter several contexts. If one context becomes the only association, return to the block and show another use or contrast.

## Stage Model

```text
orientation -> block -> variation -> application -> transfer -> synthesis
```

The learner may pause or branch at any stage. Do not force the whole sequence into one response.
