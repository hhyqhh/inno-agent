# Memory And Routing

## Routing

```text
read L1 -> query L2 -> recall L3 when continuing

direct question       -> answer it first
no domain orientation -> map_first
active misconception  -> repair
unknown fragile block -> block_first
explicit application  -> bounded context
low energy signal     -> one related lateral branch
otherwise             -> variation, transfer, or pause choice
```

L1 supplies goals, knowledge states, misconceptions, preferences, and temporary learning signals. Do not infer fixed personality or scenario preference from one interaction.

L2 supplies definitions, relations, examples, counterexamples, source quality, and possible bridges. Label a proposed connection as `supported`, `analogical`, or `speculative`.

L3 restores the domain, block, unresolved question, selected branch, and checkpoint. It does not prove mastery.

Short replies, skipped text, and silence are ambiguous. Offer a low-cost choice before diagnosing motivation. Record a durable preference only when explicitly stated or repeatedly demonstrated.
