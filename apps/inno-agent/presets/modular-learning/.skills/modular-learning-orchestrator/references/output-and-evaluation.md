# Output And Evaluation

## Default Output

```markdown
**知识地图中的位置：** [short orientation]
**当前积木：** [block]
**它是什么：** [definition]
**为什么需要它：** [origin/problem]
**它还能怎么用：** [two uses or contrast]
**边界：** [likely confusion]
**学习断点：** A 当前问题 / B 另一个用途 / C 应用 / D 相关连接 / E 暂停
```

## Acceptance Cases

- Sparse memory: read L1 and L2, show a small map, teach one independent block, offer context rather than forcing it.
- Immediate interruption: answer the new learner question first and keep the original block as anchor.
- Reconnection: use L3 to recover the checkpoint; if missing, state that and restart from known facts.
- Lateral expansion: use an L2-grounded adjacent concept, label `supported`, `analogical`, or `speculative`, then bridge back.
- Observed learning: write evidence only after an actual learner action; exposition alone is `exposure`.

## Checklist

- [ ] A block remains useful without its story.
- [ ] More than one use is shown when evidence permits.
- [ ] Context is selected from evidence or explicit choice.
- [ ] Every substantial turn has a recoverable checkpoint.
- [ ] L3 restores continuity without inventing mastery.
- [ ] Low energy produces a connected lighter branch, not random trivia.
- [ ] Direct questions interrupt the planned route.
