# Math delimiter fonts

`KaTeX_Size1-Regular.ttf` … `KaTeX_Size4-Regular.ttf` come from the
[KaTeX](https://github.com/KaTeX/KaTeX) project (version matching the
`katex` dependency already used by the chat math renderer). They carry the
progressively larger delimiter glyphs `( ) [ ] { }` (Size1–4) and the
stackable piece glyphs (Size4) that the word editor's OMML layout uses to
draw equation delimiters with math-appropriate stroke weights.
